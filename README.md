# ReadOnn POC

Clickable UI prototype of ReadOnn: pick a book, time-box a session, mark the text, then review on a Cornell page.

Live: https://irisbuild25.github.io/readonn-poc/

Local:

```bash
npm install
npm run dev
```

This is a front-end mock. Ask answers and the session summary are canned. Nothing is saved to a server.
